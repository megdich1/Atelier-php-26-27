# Atelier 7

### Utilisation de `htmlspecialchars()`

La fonction `htmlspecialchars()` convertit les caractères spéciaux en entités HTML.

Elle permet de protéger une application contre les attaques **XSS (Cross-Site Scripting)** en empêchant l'exécution de code HTML ou JavaScript potentiellement malveillant injecté dans un champ de saisie utilisateur, lorsque les données sont correctement échappées avant leur affichage.
