QUESTIONS DE REFLEXION - TP2

1. Pourquoi utiliser un tableau plutot que $etudiant1, $etudiant2, etc. ?
Un tableau regroupe plusieurs valeurs sous un seul nom. On peut le parcourir
avec une boucle, ajouter ou supprimer des elements, et compter avec count().
Avec $etudiant1, $etudiant2... il faudrait ecrire du code pour chaque variable.

2. Quelle difference entre $etudiants[0] et $etudiant["nom"] ?
$etudiants[0] est un tableau indexe : on accede a l'element par sa position
(un numero qui commence a 0). $etudiant["nom"] est un tableau associatif : on
accede a la valeur par sa cle (un nom), ce qui est plus lisible.

3. Pourquoi une fonction ameliore-t-elle la reutilisation du code ?
On ecrit le code une seule fois et on l'appelle autant de fois que necessaire
avec des parametres differents. Une correction se fait a un seul endroit.

4. Quelle difference entre echo et return ?
echo affiche directement une valeur dans la page. return renvoie une valeur a
l'appelant, qui peut la stocker, la calculer ou l'afficher plus tard.

5. Pourquoi separer les fonctions dans un fichier ?
Pour reutiliser les memes fonctions dans plusieurs pages avec require_once,
garder les pages courtes et les maintenir plus facilement.
